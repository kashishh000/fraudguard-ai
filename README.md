# 🛡️ FraudGuard AI

An AI-powered fraud detection dashboard that simulates real-time transaction monitoring and anomaly detection using machine learning concepts.

---

## 🚀 Overview

FraudGuard AI is a real-time financial monitoring dashboard designed to demonstrate how AI systems detect fraudulent transactions.
It visualizes live transaction streams, flags suspicious activity, and provides instant alerts.

---

## ✨ Features

* 📡 Real-time transaction stream simulation
* ⚠️ AI-based fraud detection alerts
* 📊 Live monitoring dashboard with key metrics
* 🔥 Anomaly detection visualization
* ⚡ Smooth UI animations using Framer Motion
* 🎯 Clean and modern fintech dashboard design

---

## 🖼️ Preview

Simulates how AI detects fraudulent activity based on anomalies like location mismatch and unusual spending patterns.

---

## 🛠️ Tech Stack

## 🧠 How It Works

1. System continuously generates transaction data
2. AI logic analyzes transactions in real time
3. Suspicious activity triggers fraud alert
4. System blocks transaction and notifies user
